# LifeOS 1.7.0 — Personal OS Navigation

Esta release elimina a aba Tarefas da navegação e reorganiza o produto em torno de Home, Inbox, Hoje, Próximos, Workspaces, Knowledge, Calendar e Insights.

A rota `/tasks` permanece como redirecionamento para `/inbox`, preservando links antigos. Os módulos especializados continuam disponíveis por URL durante a transição, sem perda de dados ou mudanças no backend.
