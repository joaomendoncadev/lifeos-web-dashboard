# LifeOS 1.1.2

## Correções

- Converte nomes de ícones persistidos (`BookOpen`, `Dumbbell`, `ListChecks`) em componentes Lucide reais.
- Mantém compatibilidade com emojis personalizados já armazenados.
- Substitui o campo de texto do ícone por uma seleção de ícones suportados.
- Corrige a sobreposição dos botões de editar/excluir com a sequência do hábito.
- Usa um ícone neutro como fallback para valores antigos desconhecidos.
