# LifeOS 1.3.0 — UX Foundation

- Edição de tarefas em painel lateral completo, sem prompts do navegador.
- Edição de projetos no mesmo padrão visual.
- Campos de status, prioridade, projeto, contexto, duração, data, área, prazo, ícone e descrição.
- Confirmações internas de exclusão.
- Toasts globais de sucesso e erro.
- Paleta de comandos global com `⌘K`/`Ctrl+K`.
- Atalho `N` na página de tarefas.
- Duplo clique para editar tarefas e projetos.
- Componentes reutilizáveis `EntityDrawer`, `ConfirmDialog` e `ToastProvider`.
- Melhorias de hover, foco, responsividade e animações.
